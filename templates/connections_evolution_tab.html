⚡ Evolution API (Container Autônomo)

Self-Hosted / Open-Source

Configuração do container de WhatsApp próprio da MAJ para espelhamento passivo das conversas dos vendedores via QR Code sem intermediários.

Endereço público do container Evolution API (sem barra no final).
Gerenciar Linhas no CRM

📡 Webhook Espelho de Mensagens

As instâncias criadas no M-One são configuradas automaticamente com este endpoint receptor:

{{ evolution_webhook_url }}
Eventos Espelhados:
• MESSAGES_UPSERT (mensagens enviadas e recebidas)
• CONNECTION_UPDATE (status da linha e nível de bateria)

🎙️ Transcrição Groq Whisper

Áudios recebidos ou enviados nas instâncias são decodificados e transcritos instantaneamente pela Groq Whisper Cloud (PT-BR) para alimentar a IA do Analisador de Chats.
