# Regras do Agente M-One

1. **Porta Local**: Sempre utilize a porta `5001`.
2. **Banco de Dados**: Supabase PostgreSQL IPv4 Pooler (`aws-0-us-west-2.pooler.supabase.com:6543`).
3. **Produção**: Vercel (`https://m-one.majmobilidade.com.br`).
4. **Vendas**: Nunca permitir vendas sem validação rigorosa de chassi.
5. **Sigilo**: Custos de importação restritos às roles `admin` e `support`.
